Yes, you can force text in a GitHub issue to display in monospace by using standard Markdown code blocks.

How to Force Monospace

To display an ASCII file structure perfectly, wrap your text in **triple backticks** (\`\`\`) to create a fenced code block.

```
{content: }
```

your-project/  
├── src/  
│ └── index.js  
└── package.json

```
{content: }
```

Best Practices for File Structures

- **Specify a Text Modifier**: Use `text` or `plaintext` after the first triple backticks to prevent GitHub from accidentally applying incorrect syntax highlighting colors to your file tree.
- **Use Standard ASCII/Unicode Symbols**: Use specific characters like `├──`, `└──`, and `│` instead of regular hyphens and slashes to make the tree clean and readable.
- **Keep it Concise**: Only include the relevant files and folders that matter to your issue. Collapse or omit deep, repetitive directories like `node_modules`.
- **Wrap in Details for Length**: If the file structure is very long, wrap the code block in HTML `<details>` tags so it does not clutter the issue template.

```
<details>
<summary>Click to view full project structure</summary>

\`\`\`text
my-app/
├── public/
└── src/
\`\`\`
</details>
```

You can automatically generate a perfect ASCII file structure on Windows 10 using the native **`tree` command** in Command Prompt or PowerShell.

The Best Windows Command for GitHub

Open Command Prompt (CMD) or PowerShell and run the following command inside your project folder:

```
tree /F /A | clip
```

Why this command works best:

- **`/F`**: Includes **filenames** in the tree, not just the folders.
- **`/A`**: Uses **standard ASCII characters** (`+---`, `|`) instead of extended graphics. This guarantees GitHub will render the lines flawlessly on all browsers and devices without breaking.
- **`| clip`**: Copies the output **directly to your clipboard** so you can immediately paste it into your GitHub issue.

Alternative for Beautiful Unicode Lines

If you want the prettier, modern lines (`├──`, `└──`) and are pasting into a browser that supports Unicode, simply omit the `/A`:

```
tree /F | clip
```

Here is a highly configurable PowerShell script designed specifically for generating clean GitHub ASCII structures. It supports hiding folders, capping depth, and limiting the total output length.

The PowerShell Script (`Get-GitHubTree.ps1`)

Save the following code into a file named `Get-GitHubTree.ps1` in your project folder, or copy-paste it directly into your PowerShell window to define the function.

```
function Get-GitHubTree {
    [CmdletBinding()]
    param(
        [string]$Path = ".",
        [string[]]$Exclude = @("node_modules", ".git", ".github", "bin", "obj", "dist"),
        [int]$MaxDepth = 0,
        [int]$MaxLines = 100,
        [switch]$CopyToClipboard
    )

    function Show-Tree {
        param([string]$CurrentPath, [string]$Indent, [int]$CurrentDepth)
        
        # Enforce max depth constraint
        if ($MaxDepth -gt 0 -and $CurrentDepth -gt $MaxDepth) { return }

        # Get all files and directories, filtering out excluded names
        $Items = Get-ChildItem -Path $CurrentPath | Where-Object { $_.Name -notin $Exclude }
        $Count = $Items.Count

        for ($i = 0; $i -lt $Count; $i++) {
            # Check line cap constraint
            if ($script:LineCount -ge $MaxLines) {
                if (-not $script:CappedMessageShown) {
                    $script:Output += "$Indent... [Output capped at $MaxLines lines] ..."
                    $script:CappedMessageShown = $true
                }
                return
            }

            $Item = $Items[$i]
            $IsLast = ($i -eq $Count - 1)
            
            # Choose appropriate ASCII connector branch
            $Marker = if ($IsLast) { "└── " } else { "├── " }
            $script:Output += "$Indent$Marker$($Item.Name)"
            $script:LineCount++

            # Recursively dive into folders
```

```
.PARAMETER Exclude

.EXAMPLE
    Get-GitHubTree -MaxLines 30 -CopyToClipboard
    Limits the tree to 30 lines maximum and automatically copies it to your clipboard.
#>
function Get-GitHubTree {
    [CmdletBinding()]
    param(
        [string]$Path = ".",
        [string[]]$Exclude = @("node_modules", ".git", ".github", "bin", "obj", "dist"),
        [int]$MaxDepth = 0,
        [int]$MaxLines = 100,
        [switch]$CopyToClipboard
    )

    function Show-Tree {
        param([string]$CurrentPath, [string]$Indent, [int]$CurrentDepth)
        
        # Guard clause: Stop digging if we exceed the user-defined maximum depth
        if ($MaxDepth -gt 0 -and $CurrentDepth -gt $MaxDepth) { return }

        # Retrieve items and filter out any names present in the Exclude array
        $Items = Get-ChildItem -Path $CurrentPath | Where-Object { $_.Name -notin $Exclude }
        $Count = $Items.Count

        for ($i = 0; $i -lt $Count; $i++) {
            # Guard clause: Stop printing if we hit the user-defined line cap limit
            if ($script:LineCount -ge $MaxLines) {
                if (-not $script:CappedMessageShown) {
                    $script:Output += "$Indent... [Output capped at $MaxLines lines] ..."
                    $script:CappedMessageShown = $true
                }
                return
            }

            $Item = $Items[$i]
            $IsLast = ($i -eq $Count - 1)
            
            # Select the correct branch symbol based on folder position
            $Marker = if ($IsLast) { "└── " } else { "├── " }
            $script:Output += "$Indent$Marker$($Item.Name)"
            $script:LineCount++

            # If the item is a folder, recursively dive into it
            if ($Item.PSIsContainer) {
                # Format the indentation lines correctly for child elements
                $NextIndent = $Indent + (if ($IsLast) { "    " } else { "│   " })
                Show-Tree -CurrentPath $Item.FullName -Indent $NextIndent -CurrentDepth ($CurrentDepth + 1)
            }
        }
    }

    # Initialize script-scoped variables to track cross-function state
    $script:Output = @()
    $script:LineCount = 0
    $script:CappedMessageShown = $false

    # Add the root directory name to the very top line
    $script:Output += (Get-Item $Path).Name
    
    # Fire off the recursive tree generation
    Show-Tree -CurrentPath $Path -Indent "" -CurrentDepth 1

    # Convert the array of lines into a single string separated by Windows line endings
    $FinalResult = $script:Output -join "\`r\`n"

    # Route the output based on whether -CopyToClipboard was supplied
    if ($CopyToClipboard) {
        $FinalResult | Set-Clipboard
        Write-Host "Success: Tree copied to clipboard!" -ForegroundColor Green
    } else {
        return $FinalResult
    }
}
```

```
        $Count = $Items.Count

        for ($i = 0; $i -lt $Count; $i++) {
            # Enforce line cap constraint
            if ($script:LineCount -ge $MaxLines) {
                if (-not $script:CappedMessageShown) {
                    $script:Output += "$Indent... [Output capped at $MaxLines lines] ..."
                    $script:CappedMessageShown = $true
                }
                return
            }

            $IsLast = ($i -eq $Count - 1)

            if ($Format -eq "Unicode") {
                $Marker = if ($IsLast) { "└── " } else { "├── " }
                $Pipe   = "│   "
            } else {
                $Marker = if ($IsLast) { "\--- " } else { "+--- " }
                $Pipe   = "|   "
            }

            $script:Output += "$Indent$Marker$($Item.Name)"
            $script:LineCount++

            # If it's a directory, recursively descend
            if ($Item.PSIsContainer) {
                $NextIndent = $Indent + (if ($IsLast) { "    " } else { $Pipe })
                Show-Tree -CurrentPath $Item.FullName -Indent $NextIndent -CurrentDepth ($CurrentDepth + 1)
            }
        }
    }

    $script:Output = @()
    $script:LineCount = 0
    $script:CappedMessageShown = $false

    # Append Root directory name
    $script:Output += (Get-Item $Path).Name
    
    # Run the crawler
    Show-Tree -Path $Path -Indent "" -CurrentDepth 1

    $FinalResult = $script:Output -join "\`r\`n"

    # Direct output to screen or system memory clipboard
    if ($CopyToClipboard) {
        $FinalResult | Set-Clipboard
        Write-Host "Success: Tree copied to clipboard!" -ForegroundColor Green
    } else {

    }
```
